# 因果逻辑与终局判定

## 两个方向，一条有效路径
反向：目标 → 必要条件 → 前置成果 → 当前缺口。
正向：当前事实＋已选方案＋资源 → 候选行动 → 条件性的中间结果 → 下一状态。
两者交会处才是本轮问题。反向推导可以列条件，不得替用户把所有行动预选完。

目标条件分为：
- 可控制成果：产品、流程、技能、资产等。
- 资源条件：时间、现金、能力、协作与先后依赖。
- 外部结果：销售、用户认可、审批等，需要观察指标、验证节点及未达标处理。

“有营销计划”不等于“销量已成立”。推导闭合指所有条件的行动、依赖、验证与调整路线都有交代，不是充分证明外部结果必然发生。禁止用少量成功案例证明必然性。

## 每次状态转移
对每项选择记录：
父状态 → 行动承诺 → 计划产出 → 新增条件/代价 → 尚未解决的问题。
产出只有用户报告或经授权检查后才进入事实。暂定时间、成本必须列依据和假设，不能按选择自动扣减真实资金或改变事实状态。

例：选择“样板＋开发记录” → 决定制作一个展示场景和一期视频 → 新增素材、剪辑、发布节奏等条件 → 后续可以选择内容路线。程序原型、产品可玩性、销售转化、房车资金仍未解决。

## 目标固定与分支
- 目标版本有编号；仅用户明确更改才升版，并重新评估条件。
- 存储完整节点与父子关系，不只保存字母串。
- 选项解释与编号展示后冻结，不能为了好卦改排。
- 非选中分支可保留简述；改选分叉时，旧后代归档，新分支重新推导。
- 已有决定只有在依赖仍成立、用户明确承接后才能移植。
- 相同卦象不代表相同状态；成本、历史、缺口仍由完整账本决定。
- 不要求八维各走一遍；不设步数阈值。
- 现实约束与卦象意向冲突时，生成准备、缩小行动单位或调整顺序等选项；不能自动改目标，也不能神化资源来源。

## 每轮闭合检查
逐项检验：
1. 所有目标条件是否有来自有效选择节点的行动覆盖？
2. 每个行动的前置依赖能否追溯到现有事实或另一项计划产出，且无循环？
3. 重大决策、时间/预算/能力冲突是否仍未解决？
4. 外部结果是否有指标、验证时点、未达标调整路径？
5. 汇总时是否需要凭空补一项重大决定？

任何一项不满足则未闭合。每轮只推进最关键缺口；必要时拆分新的条件，不能机械删除缺口以达到结局。

## 表达
可以说“这一选择把路径中的某项条件确定下来”“本轮显化的是行动次序”。
不能说“选择发布就注定十万销量”“卦象已经证明收入必然达成”。
象征解读不转换成概率。把推导理由、条件、反例或可能阻断因素写清楚，保留仪式感而不伪造证据。
