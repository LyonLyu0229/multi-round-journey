# 排盘与起卦算法 v2

## 计算入口
使用 scripts/journey_engine.py，不凭模型生成计算结果。
依赖固定在 scripts/requirements.txt，并随包置于 scripts/vendor；脚本优先读内置依赖，不修改全局 Python。
更新依赖必须重跑测试并记录版本，不能静默混用历法。

命令（在 Skill 目录执行）：
- python -X utf8 -B scripts/journey_engine.py chart --json '{"calendar":"lunar","year":2000,"month":1,"day":1,"time":"12:00","birthplace":"北京","timezone":"Asia/Shanghai"}'
- python -X utf8 -B scripts/journey_engine.py hex --base 20 --hour 7 --path '[[1],[4,5]]'
- python -X utf8 -B scripts/journey_engine.py audit --input ledger.json
Windows 终端若重写 JSON 引号，使用 --input UTF-8 JSON 文件或 --input - 从标准输入读取。脚本错误返回非零退出码。
- python -X utf8 -B -m unittest discover -s tests -v

## 排盘时间口径
calendar 为 solar 或 lunar；year/month/day/time 必填，lunar 的 leap 为布尔值，闰月不写负月份。出生城市和 IANA timezone 必填，夏令时重复时刻可传 fold=0/1。
time 为 HH:MM[:SS]；time_end 为可选结束时间，最多48小时，跨午夜用 end_date=YYYY-MM-DD（民用公历）明确。
缺准确出生时间时不能擅自用中午代替。范围每分钟及边界末端计算候选，并按四柱＋起卦出生数去重，输出候选起止及夏令时折叠候选。
不存在的夏令时钟表时间报错；重复时间输出两种真实时刻，除非用户指定 fold。

以出生地民用时间定位真实 UTC 时刻，记录历史时区、夏令时、标准时间；默认不做真太阳时修正。
四柱年/月的节气界点以真实时刻换算到 UTC+8 后交给 lunar-python 判断；日柱、时柱用出生地扣除 DST 的标准钟表时间，日柱当地午夜换日（sect=2），晚子时时柱沿用库的明确口径（子时按次日日干起时）。
农历输入按所选民用日期的中国历法日期解释；境外出生涉及家属记录历法差异时先确认。
出生起卦的农历年/月/日、时支取标准钟表时刻转换的结果，记录与原始民用输入的差别，不混用节气年与农历年。
仅给出的分钟被视为该分钟准确时刻；若实际为大约，必须保留范围，尤其节气附近。
不以五行数量推断格局、能力或喜用神。

## 初始卦：选定的出生时刻取数
农历年支子1至亥12，月用1—12（闰月沿用并记录），日1—30，时支子1至亥12。
B=年支序数+月+日；H=时支序数。
r_k(x)=((x-1) mod k)+1，余零取k。
上卦=r_8(B)，下卦=r_8(B+H)，动爻=r_6(B+H)。
先天八卦序：乾1 兑2 离3 震4 巽5 坎6 艮7 坤8。
每卦用自下而上的三爻表示：乾111、兑110、离101、震100、巽011、坎010、艮001、坤000。
下卦三爻在先，上卦三爻在后；翻转动爻（1—6由下至上）查64卦表。
八字与出生数起卦是两个体系；用出生时刻起卦是本工具选定用法，不宣称是唯一传统排盘法。

## 路径重起卦：自定义扩展 journey-v2
选项展示前固定数码1—10，不能选择后改映射。
P=0；每次决策按选中数码升序，依次 P=11P+c，结束 P=11P（追加0）。
n=有效决策数；上卦=r_8(B+P)，下卦=r_8(B+H+P+n)，动爻=r_6(B+H+P+n)。
P 用任意精度整数，JSON 输出十进制字符串，不经过浮点数。
组合 [[4,5]] 与先后 [[4],[5]] 编码不同。重复码、布尔值、空决策、超范围数码拒绝。
n=0/P=0 等于初始卦；没有当前时间、项目文字哈希或随机数。
只对有效路径重算；分支更改保留历史，记录修订原因。
64个卦可以重复，不能据同卦合并项目状态。没有规则规定每轮卦一定不同。

## 解读纪律
用本卦描述本轮主题、动爻指出行动分寸、变卦讨论后续关注点。引用爻辞需核对《周易》对应爻文并标来源；不凭空编写，不能把固定变卦表套在所有动爻上。
每次具体说明对时机/重点/顺序/准备条件的影响，之后和资源及必要条件相互检查。
算法可复算只代表一致性，不代表预测得到科学验证。不能输出命理成功百分比、医学判断、确定收入或宿命强迫。
